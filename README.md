# A Wireless Autonomous Real-Time Underwater Acoustic Positioning System

[![DOI](https://img.shields.io/badge/DOI-10.3390%2Fs22218208-blue)](https://doi.org/10.3390/s22218208)

This repository hosts the datasets used to evaluate the real-time acoustic tracking
system developed by the STELLA MARE laboratory, including performance analyses of
accuracy, reconstruction rate, and power consumption.

## Reference

Manicacci, F.-M., Mourier, J., Babatounde, C., Garcia, J., Broutta, M.,
Gualtieri, J.-S., & Aiello, A. (2022). *A Wireless Autonomous Real-Time Underwater
Acoustic Positioning System.* **Sensors**, 22(21), 8208.
[https://doi.org/10.3390/s22218208](https://doi.org/10.3390/s22218208)
(open access, CC BY 4.0)
